To get started use /setup. A message will appear to ask for your region, KC server number (formatted as ####) and the channels you use to receive upcoming event notifications and what channel you want the title call messages to post in.

Some additional optional steps you can take: /manage will open a panel for some extra selections, from there choose Alliances, a new message will appear for your alliance management.
Here you can enter all of your alliances in the server for rotations.
Next use /rotationevents to select the events your server has chosen for specialized posts in the title call channel.
