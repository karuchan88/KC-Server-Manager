Getting Started

Setup

After installing the bot in your server, use /setup to assign region and server as well as assigning your upcoming events channel and title callout channel.

The next step is to assign your rotation events if you have any via /manage. This includes a dropdown menu with the ability to select multiple items.
In this same command you can also assign your alliances for selection in those rotation events selected.

Should the bot miss an event post for any particular reason you can use the command /reparse and then enter the message ID or message link to have the bot run it again.
If the bot still doesn't pull any events then check that the bot is online and message the bot owner.
Additionally, you can setup a bot status channel and use the command /setupstatus that provides a consistent update every 60 seconds. Should the bot stop responding the message won't update.

Polls

A unique feature with this bot is the ability to run polls not just in multiple translating channels but also with proxy voting. This is in the instance that some leadership or other members of your server aren't on discord but still wish to be a part of the vote.
To use this feature, setup your channels in categories first via /pollsettings.
Two categories are auto created upon initial setup of the bot "leadership" and "general". You'll click Language Channels and assign them using the channel ID or mentioning the channel if you know the exact name (It is far easier to copy the channel ID than trying to mention).
Next after assignments you can use the command /poll.
It will ask for the channel category, the languages to post in, the question being asked, and up to 4 options as answers to vote with.
Submit for the first language, then translate the question and answers using something like Google Translate to submit for each of the other languages posted.
Once all languages have been submitted, a review option will be present and if everything looks good you can send the message.

Please note that polls will be limited to 10 per day and resets at midnight US MST time.
