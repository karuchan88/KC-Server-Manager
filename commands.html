Bot Command Library

Here are the current commands for Server Manager. Some commands are permission based either by the designated roles created by the bot after setup or strictly for the bot owner.
Any Admin in a server without one of the bots roles can also use the Manager roles.
Only the owner can use the Owner commands.

  • Owner Commands
  • /ownerpanel - Opens a panel to show list of, add, or delete any events that might be on a servers' rotation. This is the hardcoded list of selections available on setup.
  • /synccommands - Synchronizes any new commands with Discord after restart to implement updates.
  • /listrotationoptions - lists all events listed as options for alliance rotations. This list is available to servers via /rotationevents.
  • /addrotationoption - add a new event to the rotation selection for servers to use.
  • /removerotationoption - removes an event from the rotation selection for servers to use.
  • /testgemini - Tests the AI API with hardcoded event announcement.
  • /listearlevents - Lists all known earl events for AI parser to determine if bot should post for Earl or Duke.
  • /addearlevent - add a new earl event for the AI parser.
  • removeearlevent - removes an earl event from the AI parser in the unlikely event of a KC update.
  • /botban - bans a user from all functions of the bot. Only used in the most extreme necessary measures.
  • /botunban - unbans a user and restores access to the bot.
  • Manager commands
  • /setup - Connect the title calls to channels and assign server number and region.
  • /createevent - Manually create an event post if the bot can't detect one.
  • /manage - Opens server management panel for updating names, assign bot status embed in channel of choosing, Assign rotation events for the server, update alliances for the rotation selection, and reparse an event post if a title call didn't appear.
  • /alliances - add, remove, or list the current alliances in the server.
  • /rotationevents - Manage the server rotation events using a multi-select dropdown menu.
  • /rehydrate - reattaches buttons to a title call post that might have become disconnected during bot restart.
  • /pollsettings - In a future update this command will allow the assignment of language channels into categories for polls.
  • /poll - Create a poll after selecting the category and custom options that can then post into multiple language channels as needed.
  • Special Permissions - delete reservation entries, manage all other reservations, proxy vote for title calls and upcoming polls.
  • Public Commands
  • /help - opens the help menu with brief descriptions and copy/paste commands.
  • /checkserverstatus - Shows the current configurations for the server.
  • /ping - checks if the bot is online.
